# Fonts

The site hosts its own fonts, so no visitor data goes to a font service.

| Family | Used for | License |
| --- | --- | --- |
| Newsreader | The opening statement, page and post titles, post text | SIL Open Font License 1.1 |
| Geist | Menu, lists, CV and everything else | SIL Open Font License 1.1 |
| Geist Mono | Code | SIL Open Font License 1.1 |

The files are the Latin and Latin Extended subsets distributed by Fontsource.
The licence texts are next to this file. To change a font, replace the files
and update the `fonts` block in `astro.config.mjs`.
